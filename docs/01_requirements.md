# 01 Requirements - My Finance App

## 1. 帳本

### 必要功能

- 建立預設帳本：日常帳本。
- 帳本支援幣別，預設 TWD。
- 帳本支援月起始日，預設每月 1 日。

### 後續功能

- 多帳本。
- 共享帳本。
- 帳本封面與顏色。

## 2. 交易類型

### 支出

支出資料包含：

- 金額
- 類別
- 帳戶
- 成員
- 商家
- 標籤
- 備註
- 日期時間
- 附件
- 是否報銷

### 收入

收入資料包含：

- 金額
- 類別
- 入帳帳戶
- 成員
- 商家或來源
- 標籤
- 備註
- 日期時間

### 轉帳

轉帳資料包含：

- 金額
- 轉出帳戶
- 轉入帳戶
- 類型：轉帳、投資、贖回、存錢、取錢
- 備註
- 日期時間
- 標籤

轉帳不得列入一般支出或收入統計。

### 借貸

借貸資料包含：

- 類型：借入、借出、還款、收款
- 金額
- 對象
- 關聯帳戶
- 還款日
- 備註
- 標籤

## 3. 帳戶管理

帳戶類型：

- 現金
- 銀行帳戶
- 信用卡
- 電子支付
- 儲值卡
- 禮券
- 投資帳戶
- 週轉金

帳戶支援：

- 初始餘額
- 目前餘額
- 隱藏或封存
- 常用置頂

## 4. 類別管理

- 支援大類與小類。
- 支援收入、支出、轉帳、借貸各自分類。
- 支援新增、編輯、封存。
- 以 category_id 作為主鍵，不依賴名稱判斷。

## 5. 商家管理

- 手動建立商家。
- 常用商家排序。
- 關鍵字搜尋商家。
- 後續支援附近商家查詢。

## 6. 報表

初期報表：

- 本月收入
- 本月支出
- 本月結餘

後續報表：

- 大類
- 小類
- 帳戶
- 商家
- 標籤
- 成員
- 趨勢圖

## 7. 備份與還原

- 匯出 SQLite 與附件。
- 備份檔可換機匯入。
- 後續支援加密備份。
- 後續支援雲端自動備份。

## 8. 雲端發票

- 儲存手機條碼與授權資料。
- 手動同步雲端發票。
- 自動建立候選交易。
- 對獎通知。
- 與既有交易比對並合併。
